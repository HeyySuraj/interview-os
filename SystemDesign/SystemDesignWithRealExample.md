# Interview Prep

System design interview prep for absolute beginners, built around one framework you can reuse on any question.

Most candidates fail for a reason that has little to do with how much tech they know. They start drawing boxes before the problem is even clear, then run out of time on the wrong system. This course fixes that with a six-step framework that turns a vague prompt like "design a URL shortener" into something you can finish in 45 minutes. Then the framework gets applied to four real interview problems, each hiding the exact trap the interviewer is quietly watching for.

📚 What you'll learn:
1️⃣ The six-step framework that stops you from building the wrong system under pressure
2️⃣ How to Design a URL shortener that survives a link going viral (caching, hotkeys, 301 vs 302)
3️⃣ How a Rate Limiter really works, and why the token bucket beats fixed and sliding windows
4️⃣ How to build a Notification System where a duplicate SMS almost never reaches the user
5️⃣ How a News Feed loads in under a second, and the celebrity problem that breaks the naive design
